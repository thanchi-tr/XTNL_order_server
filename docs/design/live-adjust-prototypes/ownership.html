How ownership works

✓
Any manual move makes the stop yours
Tighter or looser, in any platform. The server sees it on the broker stream and tells it apart from its own amends.
✓
The server never fights you
It keeps deciding and advising at each bar end, but sends nothing for a stop that is yours.
✓
Hand back when you choose
An audited request with your reason. From the next bar end the server may move it again, only ever tighter than the stop at the broker at that time.
▲
A move you make during a send
Caught by the confirming read: paged critical (stop loosened by a send) and the stop is blocked until resolved.
Hand back to the order-server

Hand back

From the next bar end the server may propose moves for this stop again (Phase 3: you still approve each one). It only ever tightens from the stop as it is at the broker at that time; it never loosens.
